Privacy Policy

Last updated: November 9, 2026

Overview

Global Atmospheric Monitor is an independent scientific visualization initiative developed by Alejandro Jaramillo-Moreno.

This policy describes how Google Drive authorization is used for scientific data processing and how it relates to visitors of the public website.

Google Drive Access

The project's authorized processing application uses the Google Drive API with the drive.readonly OAuth scope.

This scope permits read-only access to files in the authorizing Google account's Drive. The application is intended to retrieve only the reference climatology files required for Global Atmospheric Monitor.

The application does not request permission to modify, delete, or upload Google Drive files.

Use of Google Data

Retrieved scientific files are used to compute atmospheric anomalies and prepare public visualization products.

Google account information and OAuth credentials are not included in public visualization products.

Google Drive data are not used for advertising or for training artificial intelligence models.

Security and Retention

OAuth credentials are used only for authorized scientific processing. They are not published in the project's source repository or website.

Access can be revoked by the authorizing Google account through Google Account settings.

Scientific reference files remain in the authorized Google Drive storage until they are updated or removed by the account owner.

Website Visitors

The public atmospheric visualization does not require visitors to sign in with Google.

The application does not intentionally collect personal information from visitors or use advertising cookies.

The website is hosted through GitHub Pages. GitHub may process technical information associated with website access according to its own privacy policies.
