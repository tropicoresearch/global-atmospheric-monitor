Global Atmospheric Monitor

Daily Global Atmospheric Conditions and Anomalies

An interactive scientific visualization initiative developed by TRÓPICO.

About the Project

Global Atmospheric Monitor aims to provide an interactive visualization of recent atmospheric conditions and anomalies across the globe.

The project uses NOAA Climate Prediction Center CORe daily atmospheric analyses and reference climatologies calculated for 1991–2020.

Scientific Data

The monitoring system is being developed to display atmospheric temperature, precipitation, moisture, horizontal winds, geopotential height, and vertical motion.

The daily reference climatologies are calculated using the original NOAA CPC CORe spatial grid.

Google Drive Integration

Google Drive is used by the project's authorized scientific processing tools to retrieve reference climatology files.

The Google Drive connection uses read-only authorization. Website visitors do not need a Google account or access to Google Drive.
